# Student Placement Prediction using Machine Learning

## About the Project
This project uses Machine Learning to predict whether a student
will get placed based on academic performance, skills, projects,
internships, certifications, and DSA scores.

## Features Used
- CGPA
- Skills
- Projects
- Internships
- Certifications
- DSA Score

## Technologies Used
- Python
- Pandas
- Machine Learning
- Google Colab
- Scikit-learn (if used)

## Example Prediction
Input:
- CGPA: 8.5
- Skills: 5
- Projects: 1
- Internships: 2
- Certifications: 5
- DSA Score: 85

Prediction: Placed

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.
4. Enter student details to generate a prediction.
